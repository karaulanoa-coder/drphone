# Уведомления о заявках в Telegram

Сайт — статика на GitHub Pages, своего сервера нет. Чтобы форма «Заказать
звонок» могла прислать уведомление владельцу, используется бесплатный
Cloudflare Worker: он принимает заявку с сайта и пересылает её в Telegram.
Токен бота хранится только в Cloudflare (секрет), в коде репозитория его нет.

Всё бесплатно, занимает ~10 минут. Нужен только обычный аккаунт Cloudflare
(email + пароль, без привязки карты для free-тарифа).

## 1. Создать Telegram-бота

1. Откройте в Telegram чат **@BotFather** → `/newbot`.
2. Придумайте имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — сохраните его.
4. Напишите своему новому боту любое сообщение (например «привет») — это
   обязательно, иначе бот не узнает, куда слать уведомления.

## 2. Узнать chat_id владельца

1. В браузере откройте:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
2. В ответе (JSON) найдите `"chat":{"id":123456789, ...}` — это и есть
   `chat_id`. Если ответ пустой — убедитесь, что сообщение боту из шага 1.4
   отправлено, и обновите страницу.

## 3. Завести Cloudflare Worker

1. Зарегистрируйтесь / войдите на [dash.cloudflare.com](https://dash.cloudflare.com).
2. В меню слева: **Workers & Pages → Create → Create Worker**.
3. Дайте воркеру имя, например `drphone-notify`, нажмите **Deploy** (сначала
   поднимется заготовка — это нормально).
4. Откройте **Edit code**, удалите содержимое и вставьте код из файла
   [`telegram-notify.js`](./telegram-notify.js) из этого репозитория. **Deploy**.
5. Вернитесь в настройки воркера → вкладка **Settings → Variables and Secrets**:
   - добавьте секрет `TELEGRAM_BOT_TOKEN` — вставьте токен из шага 1.3;
   - добавьте секрет `TELEGRAM_CHAT_ID` — вставьте chat_id из шага 2.
   - сохраните (Deploy/Save).
6. На странице воркера скопируйте его адрес — что-то вроде
   `https://drphone-notify.<ваш-поддомен>.workers.dev`.

## 4. Подключить адрес к сайту

В файле `assets/main.js` замените строку:

```js
const CALLBACK_ENDPOINT = 'https://REPLACE-ME.workers.dev/notify';
```

на реальный адрес воркера + `/notify`, например:

```js
const CALLBACK_ENDPOINT = 'https://drphone-notify.ivan.workers.dev/notify';
```

Закоммитьте и запушьте — GitHub Pages обновит сайт за минуту-две.

## 5. Проверить

Откройте сайт, заполните форму «Заказать звонок» и отправьте. В Telegram
должно прийти сообщение с именем и телефоном. Если нет — проверьте:
- консоль браузера (DevTools → Console/Network) на ошибки запроса;
- что секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` сохранены без
  лишних пробелов;
- что вы один раз написали боту (шаг 1.4) — без этого Telegram не отдаст
  chat_id и не разрешит боту писать первым.

## Почему так, а не токен прямо в main.js

Если вставить токен бота прямо во фронтенд-код, он будет виден всем в
исходниках страницы, и кто угодно сможет слать от имени бота произвольные
сообщения в ваш чат (спам поддельными «заявками»). Воркер решает это: токен
лежит только на сервере Cloudflare, а сайт обращается к воркеру, не к
Telegram напрямую.
